# Aether

Aether — The most powerful local + hybrid AI agent system. Flutter cross-platform (Windows/iOS/Android). Grok, Claude, Gemini, local Ollama. Advanced agents, memory, voice, tools. Built for 2026 and beyond.

## Android APKs

Prebuilt release APKs for the suite are in [`apks/`](./apks/):

| App | APK |
|-----|-----|
| Aether | [apks/aether.apk](./apks/aether.apk) |
| xAI Toolkit | [apks/xai-toolkit.apk](./apks/xai-toolkit.apk) |
| AssetForge | [apks/assetforge.apk](./apks/assetforge.apk) |
| DevForge | [apks/devforge.apk](./apks/devforge.apk) |

```bash
flutter pub get
flutter build apk --release
```
